# School-Work

在校期间的课程实验与学习记录合集，由原 `NEUQ-Experiment`（本科，东北大学秦皇岛分校）与 `XDU-Learning`（研究生，西安电子科技大学）两个仓库合并而来。

```
School-Work
├── NEUQ-Experiment          本科课程实验
│   ├── Assembly-Experiment  汇编程序设计
│   ├── CO-Experiment        计算机组成原理实验（Verilog）
│   ├── Compile-Experiment   编译原理实验（词法 / 语法分析）
│   ├── DS-Experiment        数据结构与算法
│   ├── Interface-Experiment 微机接口实验
│   ├── Linux-Experiment     Linux 内核分析
│   ├── ML-Experiment        机器学习导论实验
│   └── OS-Experiment        操作系统算法实验
└── XDU-Learning             研究生阶段学习记录
    ├── AI-Learning          人工智能（CS188、scikit-learn 等）
    ├── Go-Learning          Go 语言
    ├── JVM-Learning         JVM
    └── Spring-Learning      Spring
```

各子目录下另有独立的 `README.md`，包含更细的说明。
